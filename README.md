# ZimboVillagers

Живые поселения для Minecraft Java Edition: жители работают, добывают и перевозят материалы, строят дома, торгуют и изучают технологии. Игрок может помогать деревне или управлять её развитием в роли мэра.

## Установка

- Minecraft Java Edition **1.20.1**.
- Minecraft Forge **47.4.0–47.x**, Java **17**.
- Поместите `ZimboVillagers-0.9.3-preview.jar` в папку `mods` выбранного профиля Forge.
- Удалите из этого профиля предыдущий JAR мода перед установкой новой версии: одновременно должна находиться только одна его версия.
- Перед обновлением существующего мира сделайте резервную копию.

## Первые шаги

Создайте обычный мир и найдите поселение. Деревни генерируются автоматически. Общайтесь с жителями, выполняйте задания и пользуйтесь рабочими блоками правой кнопкой мыши. Для управления поселением служит мэрия, для размещения дорог и зданий — инструмент мэра.

Подробное управление описано в [руководстве игрока](docs/PLAYING.md). Все команды, права доступа и примеры — в [справочнике команд](docs/COMMANDS.md). В игре: `/zimbovillagers help`.

## Состояние версии

**0.9.3-preview — предварительная сборка, не релиз 1.0.** Автономное снабжение и полное строительство первого нового дома подтверждены в сохранённом тестовом мире: жители сами получили все 465 материалов, а проверка подтвердила полную геометрию и пригодность дома для жилья. Полное развитие деревни до максимального уровня, весь каталог ресурсов и разные начальные миры ещё требуют проверки. Исправление генерации новых шахт не перестраивает автоматически шахты в старых мирах.

Название мода изменено на ZimboVillagers. Для совместимости сохранений внутренний идентификатор остаётся `villageastra`.

В 0.9.2-preview кузница V получила дорогой рецепт усиленного обруча VI из ресурсов Верхнего мира. Незеритовый рецепт сохранён. Все 24 конечные перестройки прошли общий набор из 43 серверных проверок при подготовленных исследованиях и запасах; ожидающие строители теперь освобождают место установки. Условия и границы проверок конечных уровней — [самостоятельное развитие](docs/AUTONOMY.md).

## Исходники и сборки

[Репозиторий](https://github.com/Kalashmak/ZimboVillagers) · [Готовые сборки](https://github.com/Kalashmak/ZimboVillagers/releases)

Для сборки из исходников нужны JDK 17 и Python 3.11 или новее:

```text
python tools/astra.py run build-check -- compileJava test build
```

Готовый JAR появится в `build/libs/`. Подробнее: [сборка и проверки](docs/BUILDING.md). Перед игровыми проверками ознакомьтесь с условиями Minecraft; соглашения не принимаются автоматически.
