# Сборка и проверка ZimboVillagers

Нужны JDK 17, Python 3.11+ и доступ к сети для первой загрузки Gradle и зависимостей. Укажите `JAVA_HOME` на каталог JDK. Gradle Wrapper входит в репозиторий; системный Gradle не требуется.

```text
python tools/astra.py run build-check -- compileJava test build
```

Результат: `build/libs/ZimboVillagers-0.9.1-preview.jar`. Используйте основной JAR, а не `sources` или промежуточный архив. Для игры нужны Minecraft 1.20.1 и Forge 47.4.0–47.x. [Установка и управление](PLAYING.md).

Обёртка сохраняет полный вывод в `build/astra-runs/` и печатает короткую сводку. Ключ `--evidence` сохраняет лог в `docs/runs/`. Чтение существующего лога:

```text
python tools/astra.py digest build/astra-runs/build-check.log
```

## Проверка команд на игровом сервере

```text
python tools/astra.py run commands-check --timeout-min 20 -- compileJava test build runGameTestServer -PgtOnly=zimbo_commands
```

Два GameTest проверяют регистрацию `/zimbovillagers`, справку, чтение состояния, ограничения прав и фактическое начало/отмену сопровождения жителя. Unit-тесты проверяют доменную логику и ресурсы. Результаты JUnit находятся в `build/reports/tests/test/`.

`-PgtOnly` отбирает GameTest по части имени или пакета сценариев. Без фильтра запускается весь набор; успешный отдельный набор не подтверждает весь мод. GameTest создаёт отдельный каталог `run-gametest/session-*`. Клиентские проверки могут создавать миры и занимать существенно больше времени.

## Запуск клиента для разработки

```text
python tools/astra.py run client --timeout-min 120 -- runClient
```

Каталог клиента — `run-client/`. По истечении таймаута обёртка завершает процесс, поэтому для обычной игры используйте установленный Forge и собранный JAR. Ознакомьтесь с условиями Minecraft перед запуском; при необходимости принятия соглашения сделайте это самостоятельно.

## Состав исходников

- `src/main/java` — мод, клиентские проверки и GameTest.
- `src/main/resources` — переводы, модели, рецепты, настройки баланса и метаданные Forge.
- `src/test/java` — JUnit-тесты.
- `docs/addenda/v0.7/data/balance.json` — дополнительный каталог баланса, включаемый `processResources` в JAR; этот файл необходим для полной сборки.
- `tools` — обёртка запуска и проверка результатов игровых сценариев.

Внутренние пакеты и идентификаторы `villageastra` сохранены ради совместимости миров. Игровые команды используют только `/zimbovillagers`; полный [справочник](COMMANDS.md).

## Статус проверки версии

Версия остаётся **preview**. Автономное снабжение первого нового дома и его полная геометрия подтверждены отдельной проверкой сохранённого мира. Развитие до максимального уровня и воспроизводимость на разных начальных мирах ещё требуют проверки. Полный последний набор GameTest не подтверждён: в предыдущем групповом запуске тест реки завершился неудачно, при отдельном запуске прошёл; причина расхождения ещё не установлена.
